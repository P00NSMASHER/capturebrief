Included 14-day watch

Only the assumptions touched by a change reopen.

1. Delivered baselineCurrent action, source/rule versions, resource hashes, references, and assumption dependencies are fingerprinted.
2. Fresh observationA new amendment, attachment hash, source version, rule version, or reference state is observed.
3. Explicit deltaThe watch records what changed and which stored dependency keys match.
4. Human reviewOnly affected assumptions become REVIEW_REQUIRED. The prior decision remains preserved.

CaptureBrief never silently changes the original finding or rule applicability because a newer source appeared.

What ships to the buyer

A concise brief plus an inspectable evidence package.

  • brief.md — short decision handoff.
  • decision-evidence.html / .md — exact passages, versions, rule review, and version deltas.
  • decision-summary.json — machine-readable reviewed conclusions.
  • source-version-manifest.json — public evidence identities and hashes without raw source text.
  • watch-baseline.json — privacy-minimized baseline for the included 14-day targeted watch.
  • delivery-manifest.json — SHA-256 and byte length for every delivered file.

The bundle is not produced unless the case passes CaptureBrief's release gate and the Decision Evidence trace is complete.
